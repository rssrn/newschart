# Frontend Polish Ideas

Prioritized by impact. Check off when implemented.

## High Impact

- [x] **Dark map theme** — Deep slate (`#0f1923`) or dark navy background, lighter country outlines. Most transformative single change.
- [x] **Callout cards — frosted glass** — Replace solid blue border with `backdrop-filter: blur(12px)`, semi-transparent background, subtle drop shadow.
- [ ] **Branding header** — "NewsChart" wordmark top-left, distinctive serif font (e.g. Playfair Display or DM Serif Display), one-line tagline.

## Medium Impact

- [ ] **Controls panel** — Wrap top-right radio buttons in a grouped card with section labels ("Source" / "Projection") and styled toggle buttons.
- [ ] **Typography upgrade** — Distinctive serif for story headlines (e.g. Spectral, Lora), refined sans for body (e.g. Source Sans 3). Drop system font defaults.
- [ ] **Country highlight color** — Replace mid-blue fill with something more cartographic: warm amber/gold (`#c9a84c`) or rich teal.
- [ ] **Timeline slider** — Show actual date prominently above track, add subtle day tick marks, styled gradient track.

## Lower Impact / Nice to Have

- [ ] **Connector lines — animated dashes** — Animated `stroke-dashoffset` SVG lines to pulse from country to callout.
