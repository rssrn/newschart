# NewsChart

NewsChart displays top world news stories on an interactive world map. Stories are automatically ingested from news sources, summarised and geo-tagged using AI, then presented as callouts positioned on a Mercator projection.

## Stack

- **Backend**: Java 21, Spring Boot, MongoDB, Google Gemini API
- **Frontend**: React, react-simple-maps
- **Testing**: Testcontainers, React Testing Library, Playwright
